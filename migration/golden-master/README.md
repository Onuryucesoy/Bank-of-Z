# Golden-master harness

Phase 0 freezes the API by recording what z/OS Connect returns today and requiring the Java service to return the
same thing. Two kinds of data live here:

| Directory | Contents | Used by |
|---|---|---|
| `fixtures/<ASSET>/` | **Synthetic** fixtures for the Phase 2 wave-1 read-only operations (INQCUST, INQACC, INQACCS, INQTRAND, INQTRANL), generated by `migration/tools/make_golden_fixtures.py` | `GoldenMasterFixtureTest` |
| `recordings/<ASSET>/*.json` | **Captured** production request→response pairs (empty until Phase 2) | `GoldenMasterReplayTest` |

Tests are the `goldenMaster` JVM test suite of [`migration/java-service`](../java-service) and run with
`gradle build` / `gradle goldenMaster`.

## Fixture layout

- `manifest.json` — asset, schema paths and the API call (`method`, `path`, `status`, OpenAPI `schema`)
- `request.json` — zosAsset request (COMMAREA / IMS message JSON), validated against `providerFiles/gen/requestSchema.json`
- `response.json` — zosAsset response, validated against `providerFiles/gen/responseSchema.json`
- `api-response.json` — the OpenAPI body the REST API returns, validated against the `openapi.yaml` component schema
  and diffed against the Java stub's response

Fixtures follow the generated schemas exactly: fixed-size `OCCURS` arrays keep every slot (INQTRANL has
100 `INQTRANL-TRANSACTIONS` entries, unused ones blank/zero) and `REDEFINES` group views carry the same digits as
the field they overlay.

## Recording format (placeholder for Phase 2)

One JSON file per exchange, e.g. `recordings/INQCUST/2026-11-02T101500Z-0001.json`:

```json
{
  "operation": "INQCUST",
  "capturedAt": "2026-11-02T10:15:00Z",
  "source": "z/OS Connect request/response logging (sanitised)",
  "request":  { "method": "GET", "path": "/customers/0000000001", "body": null },
  "response": { "status": 200, "body": { "customerId": "0000000001", "...": "..." } },
  "ignore":   ["/createdDate"]
}
```

- `path` is relative to the API base path `/api`.
- `ignore` lists JSON Pointers excluded from the diff; `*` matches one segment (e.g. `/transactions/*/valueDateTime`).
  Use it only for genuinely volatile values such as `$now()` timestamps (the IMS balance mapping uses `{{$now()}}`).
- Numbers are compared by decimal value (`50.0 == 50.00`), never via `double`.

Capture plan: enable request/response logging on the z/OS Connect server (or a recording reverse proxy in front of
it) for the read-only operations, scrub PII (names, addresses, phone numbers, DOB) with a deterministic mapping, and
commit the sanitised pairs here. To diff a different implementation (e.g. the Phase 2 shadow proxy or the real
z/OS Connect endpoint) run:

```bash
cd migration/java-service
gradle goldenMaster -Dbankofz.replay.target=http://localhost:9080/api
```

(Forward the property to the test JVM via `systemProperty` in `build.gradle` when that mode is wired up in Phase 2.)
